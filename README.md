# Trader.pro Frontend

> The Trader.pro Frontend is a responsive, modern web application built with Next.js, serving as the user interface for the Trader.pro trading simulation platform. It allows new traders to practice trading strategies with historical market data in a risk-free environment, featuring trade simulation, performance dashboards, and interactive charts. Deployed on Vercel, it integrates with the Trader.pro Go backend hosted on AWS EC2.

## Features

- **User Authentication**: Secure login via Firebase OAuth.
- **Trade Simulation**: Place buy/sell orders, limit orders, and stop-loss orders with a virtual ₹500,000 balance.
- **Interactive Charts**: Visualize trade performance using the TradingView API.
- **Dashboard**: Track positions, unrealized profit/loss, and simulation history.

## Tech Stack

- **Framework**: Next.js 15.x
- **Language**: TypeScript/JavaScript
- **Authentication**: Firebase OAuth
- **Visualization**: TradingView API
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **Backend Integration**: Trader.pro GoFiber API (AWS EC2)
